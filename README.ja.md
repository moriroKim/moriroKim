# キム・ジンモ · Jinmo Kim

画面からサーバー、デプロイまで、一つのプロダクトを最後まで作るフルスタックエンジニアです。

いまは5人のAI開発・研究クルー [WIGTN](https://github.com/wigtn) で、実環境で動くAIシステムを作っています。

### 作ったもの

- **[wigvo](https://github.com/wigtn/wigvo)** · 一般の電話通話を韓国語と英語でリアルタイム通訳します。相手側にアプリは不要です。[ACL 2026 System Demonstrations 採択](https://openreview.net/forum?id=9oUknRxASv) · 中央値遅延 555ms · 147通話中エコーループ 0件
- **[wigtn-plugins](https://github.com/wigtn/wigtn-plugins)** · チームの開発ワークフローを標準化した Claude Code プラグイン
- **[portfolio](https://github.com/moriroKim/portfolio)** · 問題定義、検討した代替案、試行錯誤まで記録した[ケーススタディ・ポートフォリオ](https://portfolio-six-psi-ae0mjybkx1.vercel.app/ja)

仕事の基準はシンプルです。間違えるくらいなら見せない。取り消せないものには自動化経路で触れない。
