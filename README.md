## 안녕하세요, 김진모입니다

자녀 단말에 올라가는 안드로이드 네이티브부터 수집 서버, 보호자 앱, 무중단 배포까지,
**한 제품의 전 구간을 직접 만드는** 풀스택 엔지니어입니다.

- (주)사운드마인드에서 자녀 보호·교육 서비스의 앱, 서버, 인프라를 만들고 있습니다
- 5인 AI 개발·연구 크루 [WIGTN](https://wigtn.com)에서 실제 환경에서 도는 AI 시스템을 만듭니다
- 실시간 전화 통역 시스템 [WIGVO](https://github.com/wigtn/wigvo)의 공저자입니다 · **ACL 2026 System Demonstrations 채택**
- Snowflake AI & Data Hackathon Korea 2026 준우승

일하는 기준은 단순합니다. 틀릴 바에는 보여주지 않고, 되돌릴 수 없는 것은 자동화 경로에서 건드리지 않습니다.
